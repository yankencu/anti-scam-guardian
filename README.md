# 反诈守门人（Anti-Scam Guardian）

![banner](docs/banner.png)

一个**单文件、零依赖、可插件化**的反诈互动游戏。玩家扮演"守门人"，每一条消息 3~6 秒内判断：左滑拦截，右滑放行——放走骗子按金额扣钱，误拦真消息同样扣钱，因为"只会乱拦的人，同样守不住门"。

**在线试玩**：<https://anti-scam-guardian.app.workbuddy.host/>

## 特性

- **56 条诈骗样本 + 47 条真实消息**，全部按真实案例改编，覆盖兼职刷单、公检法恐吓、AI 换脸、澳门跨境骗局等 20 类手法
- **四种玩法**：连续闯关（四关）/ 单关练习 / 地狱模式（线索隐藏、2.4 秒判定）/ 长辈版（大字慢速）
- **插件系统**：7 个官方插件 + 自定义插件安装（见下文）
- **衍生玩法**：今日一题打卡、骗子视角反转关、好友挑战码、个人反诈笔记导出、给家人的提醒图
- **零依赖**：全部代码在一个 HTML 文件里，双击即玩，离线可用（PWA）

## 快速开始

```bash
git clone <repo-url>
# 直接用浏览器打开 index.html 即可，无需构建、无需服务器
```

或部署到任意静态托管：整个项目就是一个 `index.html`。

## 插件系统

游戏对外暴露 `FZ.use({...})` 注册接口与一组生命周期钩子（`onCardShow` / `onTick` / `onJudge` / `onSettle` / `onTheme`）。玩家可以在游戏内「插件中心」粘贴代码安装第三方插件，或导入 `.fzplugin` 分享文件。

- 完整 API 文档：[docs/PLUGIN_API.md](docs/PLUGIN_API.md)
- 架构说明：[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)
- 示例插件：[plugins/examples/](plugins/examples/)

内置官方插件：

| 插件 | 说明 |
|------|------|
| 字体工坊 | 5 套界面字体 + 卡片字号缩放 |
| 话术雷达 | 自动标红消息中的高危词 |
| 计时增强 | 顶部全局倒计时条 + 临界闪烁 |
| 教练模式 | 每次判定后自动弹出套路拆解（课堂演示友好） |
| 粒子调音台 | 特效粒子密度 0.2×~1.6× |
| 成就徽章 | 9 枚里程碑徽章 |
| 色觉友好 | 蓝/橙配色替代红/绿 |
