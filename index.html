插件开发指南

一个插件是什么

一个普通的 JS 对象：用 id 标识自己，用生命周期钩子参与游戏。调用 FZ.use(插件) 完成注册。

FZ.use({
  id: 'hello',              // 必填，全局唯一
  name: '我的插件',
  ver: '1.0.0',
  icon: 'hello',
  desc: '一句话说明它做什么',
  onCardShow({ card, el }) {
    // 每张卡片滑入时触发
  },
  onJudge({ card, good, dir, combo }) {
    // 每次判定（拦截/放行/超时）后触发
  },
  onSettle(data) {
    // 一局结束：{ win, score, lost, mode, ... }
  },
  onTick({ left }) {
    // 每帧回调：left 是本卡剩余时间 0~1
  },
  onEnable() {}, onDisable() {}   // 开关时触发
});

可用钩子

钩子触发时机 · 参数
onCardShow卡片滑入 · { card, el }
onTick每帧 · { left, el }（left 为剩余时间比例）
onJudge判定后 · { card, good, dir, delta, combo }
onSettle结算 · { win, score, lost, mode, blocked, maxCombo }
onTheme关卡换肤 · 当前关卡配置
onEnable / onDisable插件开关时，用来挂载/清理自己的 DOM

插件 API（FZ 对象）

FZ.toast(标题, 副标题) 弹全局提示；FZ.storage.get/set 存你自己的数据（自动持久化）；FZ.fx.setDensity(0~1.6) 调粒子密度。

安装与分享

在插件中心点「安装自定义插件」，粘贴代码或导入 .fzplugin 文件即可；.fzplugin 就是一个 JSON，里面带着你的代码和元信息，可以随意分享。官方插件也可以直接导出成文件发给朋友。
